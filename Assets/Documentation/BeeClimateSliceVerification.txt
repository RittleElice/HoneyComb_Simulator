기후 접촉면 재사용 및 틱 분할 검증 — 2026-11-23

비교 기준
직전 기후 입력 캐시/벌 욕구 최적화가 적용된 원본을 이번 작업의 수정 전 기준으로 고정.
원본 해시: hashes.json. 원본 사본: before/. 후보: after/.
이전 대화의 다른 실행 수치가 아니라 이번 fixed-before/fixed-after 실행끼리 비교.

변경 내용
1. 기후 모델 접촉면 계산 재사용
공간 구조와 교환 객체가 같고, 물성 스냅샷 및 양쪽 셀의 float 열용량과 재질이 같으면
이전 모델의 접촉면 값(열전달 계수, 면별 질량 분율 등)을 그대로 복사.
float 곱셈/나눗셈을 대수적으로 단순화하지 않아 기존 반올림을 보존.
구조/물성/열용량/재질이 달라지면 기존 계산 경로 사용.
열·수분 Flush/Restore 및 합산 순서, 개체·난수·자원 배분 순서는 유지.

2. 메인 스레드 작업 분할
SimulationScheduler가 기본 2ms 예산의 SimulationSlice를 전달.
기후 초기화: 64셀, 접촉면: 128개, Bind: 64셀/128경계마다 예산 확인.
벌 루프: 16마리마다 확인. 자원 해결: 영역마다 확인.
시간이 넘으면 기존 yieldFrame 및 foreground 대기 콜백을 await하고 같은 위치에서 재개.
2ms는 협력적 예산이지 실행시간의 강제 상한이 아님. 단일 작업/초기 구조 구성/GC는 더 길 수 있음.
틱 전체를 성공해야 게임 시계를 확정하고 저장 체크포인트 호출.
실행 중인 관찰 창은 부분 상태를 표시·수정하지 않고 완료를 기다림.
벌 계산 LastMilliseconds는 내부 프레임 대기 시간을 빼도록 변경.
직접 CalculateMinuteAsync를 호출하는 기존 동기 경로도 유지.
저장 버전·게임 규칙·생물 파라미터는 변경하지 않음.

동일성
전체 저장 데이터 SHA-256 비교 733건 모두 일치:
- 5개 시나리오(49/1000마리, 수식 변경, 소방 변경, 가속 봉충) × 120틱 = 600건.
  각 시나리오는 60틱에서 저장·불러오기 후 계속 실행.
- 49/100/1000마리 각 3회 성능 실행의 종료 상태 = 9건.
- 소비장 분리/재삽입과 목재 비열 변경/복구 = 100틱.
- 게임 1일(1440틱), 매 60틱 상태 비교 및 720틱 저장·재개 = 24건.
실제 Editor 업데이트를 양보한 49/1000마리 45틱 실행의 종료 상태 2건도 일치.
총 735개 비교 지점에서 전체 저장 상태가 일치함.
날씨와 밀원 시드는 검증에서만 고정. 게임의 시드 생성은 변경하지 않음.

안전성/회귀 검증
- 실제 양보 중 IsInTick=true이며 시계는 직전 분에 머무름.
- 체크포인트는 IsInTick=false이고 날씨/벌/게임 시계가 일치할 때만 호출.
- 부분 틱 중단 후 재개: 1회만 확정. 부분 틱 취소: 미확정·Fault 기록·저장 체크포인트 미호출.
- 기존 GameTimeTests의 시간/겹친 실행 거부/취소/시계 확정 테스트 통과.
- BeeStartupRegression, 벌 행동 32개, 기존 벌 위치/저장 검증 통과.
- 별도 1일 행동 검증 통과.
- 기존 PersistentThermalTests의 normal/diagnostic·fresh/reused bit exact 실패는
  원본에서도 있던 알려진 문제로 별도 기록. 이번 전후 동일성 비교와 혼동하지 말 것.

해석과 한계
기후 계산의 중복 비용이 줄었고, 틱을 나눠 연속 메인 스레드 점유를 줄였음.
1000마리에서 프레임 양보로 틱 완료 지연은 늘어남. 기본 플레이의 다음 틱 대기 시작도
기존과 같이 완료 이후이므로 실제 시간 기준 시뮬레이션 처리 속도에는 이 대기가 반영됨.
게임 시간별 상태와 계산 순서는 검증 범위에서 동일하지만 렌더링 프레임 수/완료 시각은 달라짐.
실제 플레이어 렌더링 FPS, 모바일 실기기, 다중 벌통·수만 마리 성능은 미검증.
2ms를 초과하는 단일 작업과 GC가 남아 순간 끊김을 완전히 없앤 것은 아님.
단계 분할 전환 중에는 입력·저장을 막는 기존 런타임 경계가 유지됨.
다른 Unity 작업이 있는 환경이라 작은 성능 차이나 최대 지연 감소를 일반화하지 말 것.
모든 가능한 월드나 수식을 수학적으로 증명한 것이 아니라 명시된 시나리오의 완전 동일성 검증.
