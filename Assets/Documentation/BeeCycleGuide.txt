구현한 행동
섭식, 휴식, 회복, 저장, 화밀/화분 채집 및 귀환, 건설, 산란, 육아, 가온, 자원 정리.
최상위 Task 안에서 자원 획득/이동/섭식/휴식 등 선행 행동을 처리한다.
자원 실패/경로 실패/정상 완료/시간에 따른 자발적 중단을 구분한다.
한 틱에 한 번만 최상위 선택을 시도하며, 실행 중에는 욕구 갱신만 계속한다.
선택/완료/실패/중단에 따른 욕구 보정이나 재선택 억제는 없다.
모든 가중치가 0이면 그 틱은 Idle로 남고 다음 틱에 재평가한다.
외부 채집 중 자발적 중단은 귀환으로 끝낸다. 외부 이동은 상세 공간 없이 시간 모델이다.
외부 공급은 기존 8종 밀원 잔량(mg)을 실제 차감한다. 출발 시 화밀은 당분, 화분은 화분 잔량 비례로 밀원을 선택한다.
채집 완료·귀환 시 모든 벌통의 같은 밀원 요구를 합쳐 요구량 비례로 배분한다. 부족하면 실제 확보량만 가져오고, 0이면 자원 부족으로 귀환한다.
비행 중 고갈되어도 다른 밀원으로 바꾸지 않으며 중단 귀환은 차감하지 않는다. 개화·생산·날씨 손실 모델은 기존 그대로다.
꽃이나 잔량이 없는 계절에는 외부 채집으로 식량이 생기지 않으므로 시험 벌군의 무조건적인 생존은 보장하지 않는다.

자원과 틱 순서
기존 열·수분 → 기존 날씨 → 벌(집계/명령/욕구/행동 요구/배분/발열) → 시계 확정.
행동 요구를 먼저 모으고 같은 자원 경쟁은 요구량 비례로 배분한다.
실제 float32 소방 질량 변화만 벌 보유량에 이전하여 반올림으로 자원이 생기지 않게 한다.
같은 틱에 새로 얻은 자원은 다음 틱부터 후속 행동에 사용한다.
화밀을 획득할 때 당분의 화원 정보는 유지하며 함께 가져온 물은 제거하고 discardedWater에 기록한다.
체내 당분(reserve), 운반 화원별 당분/화분(cargo), 애벌레 내부 먹이를 구분한다.
기존 비정량 FillRatio 소방을 임의로 질량으로 환산하지 않는다.
정리한 격자는 그 벌의 저장 제외 대상으로 남아 저장 완료 전 즉시 되넣지 않는다.

발달·사망·열
- 알/애벌레/번데기 전환 기준 3/9/21, 성충 우화 21. 정상 조건의 봉충 기본 증가량 1/1440 매 틱.
- 알/번데기는 온도 계수, 애벌레는 온도·당분·화분·Energy 가용량으로 해당 틱 발육량을 계산한다.
- 성충은 해당 틱의 실제 행동 시간 비율 × 행동별 발달 증가량. 하루 단위 일괄 가산이나 계절별 강제 수명은 없다.
- 발달도 200 이상 또는 Health 0 이하이면 사망. 봉충 소방 연결 상실은 Health를 0으로 만든다.
- 소비장을 손에 들거나 옮겨도 소방 연결은 보존한다. 분리된 소비장의 봉충은 외기 조건으로 발육한다.
- 벌통 내부의 살아 있는 벌/봉충은 기초 발열, Heat 행동은 추가 발열. 같은 공기 셀의 열량을 합쳐 기존 열 에너지에 공급한다. 외부 벌의 열은 벌통에 넣지 않는다.

임시 수치의 규모
기존 FrameData.CellAreaScale = (85×39)/(25×12) = 11.05를 유지했다.
기존 소방 총 저장량/밀랍량/열 모델을 줄이지 않았다. 논리 소방 하나의 저장 용량은 기존 0.30ml×11.05 = 3.315ml.
벌은 실제 개체 단위이며 운반 당분 용량 20mg과 화분 용량 15mg은 독립, 화밀 요청 상한 당분15mg, 화분 요청 상한15mg, 소요8분. 실제 공급량과 남은 운반 용량으로 제한한다.
채집한 당분 비율만큼 밀원 수분도 차감하여 제거한다. 수분은 적재 용량에 포함하지 않는 기존 임시 규칙을 유지한다.
휴식 벌 대사 모델 참고값 0.452mW를 1분의 기초 발열 0.02712J로 환산했다. 활동/온도/발육 단계의 정밀 대사 모델은 아니다.
기존 일벌 소방 밀랍량은 15mg×11.05=165.75mg. 건설도1포인트당1.6575mg 밀랍에 대해 임시 당분8mg을 사용한다(약4.83mg 당분/mg 밀랍 가정).
산란 기본0.1회/분(하루144회)은 줄어든 소방 수에서 순환 확인용으로 낮춘 모델 값이며 실제 여왕 산란률의 실측 재현이 아니다.
휴식/Idle 발달0.0007/틱, 채집0.0044/틱. 우화21→사망200의 여유179 기준으로 해당 행동만 지속하면 약178일/28.3일. 실제 혼합 행동에서 여름·겨울 수명은 별도 장기 검증이 필요하다.
Energy/Health는 0~100의 모델 단위이고 Joule이나 실제 조직량이 아니다. 생물학적으로 검증된 수치 세트라고 해석하지 않는다.

파라미터 연결
각 숫자와 식은 BeeCycleSettings 및 BeeCycleParameters.asset에 있고 현재 월드 저장에도 함께 들어간다.
formulas는 작은 산술 언어이며 C# 코드를 실행하지 않는다. 변수 누락/중복 식/비정상 수치/잘못된 설정을 적용 전에 검사한다. 실제 실행 중 식이 NaN/음수 등을 반환하면 불완전 틱을 저장하지 않는다.
- feedDesire/restDesire/recoverDesire/storeDesire: ratio=해당 상태 부족 또는 적재 비율. 각각 별도 weight 사용.
- deficit: amount=현재량, available=목표량. 채집/건설/산란 필요도.
- commandChance: need=필요도. 신규 명령 생성 확률. 활성 명령은 조건을 잃을 때 종료.
- commandStimulus: need=필요도. 명령 자극. 기본 최대3×필요도.
- desireNext: amount=현재 가중치, available=0. 해당 욕구에 양의 자극이 없는 틱에만 기본 자연 감소10. 양의 자극이 있으면 자극만 더한다. 완료 등에 별도 보정 없음.
- interruptChance: elapsed=최상위 Task 경과 분.
- storagePreference: available=저장 여유량, height=전체 높이/기준 높이, distance=경로 mm.
- buildPreference: amount=격자 내 미완성 소방 개수. buildCellWeight: amount=인접 건설 소방 수.
- layCellWeight: ratio=해당 면에 봉충 존재(0/1), amount=인접 봉충 수, distance=소방 중앙까지 격자 거리.
- broodTemperature: temperature=°C. broodDevelopment: ratio=온도/영양 계수, time=틱 비율.
- larvaDevelopmentFactor: ratio=온도 계수, available=먹이 가용 비율, amount=Energy 가용 비율.
- development: actionRate=행동별 발달도/틱, time=실제 사용한 틱 비율.
- basalHeat/additionalHeat, basalSugarCost/basalEnergyCost/movementEnergyCost, moveDistance: time=틱 비율.
- feedAmount/restAmount/recoverAmount/acquireAmount/storeAmount: amount=필요/가용 공간, time=틱 비율.
- buildAmount/nurseAmount/layChance: time=틱 비율.
- forageDuration/forageSugarAmount/foragePollenAmount: 외부 채집 시간과 요청 상한(mg).
- forageSourceWeight: available=해당 자원 현재 잔량(mg). 기본 식 available로 잔량 비례 선택.
- forageWater/forageWaterAmount는 저장 호환용이며 채집에 사용하지 않는다. forageSourceId는 시험 초기 먹이의 화원 ID에만 사용한다.
- nurseNeed: amount=부족량, available=목표량. heatNeed: amount=목표와 현재의 온도 차.
자원 보존용 상한/비음수 검사, 소방의 기존 완료 이력 규칙, 25×12/5×3 대응, 초↔분 단위 변환은 모델 조정식이 아닌 시스템 제약이다.
