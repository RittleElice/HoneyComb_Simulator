유한 밀원 외부 채집 연동 검증 — 2026-11-23
확정 규칙: 기존 당분/수분/화분 수치의 단위 mg(1:1). 출발 시 잔량 비례 선택.
채집 완료·귀환 시 같은 밀원의 전 벌통 요구를 모아 요구량 비례 배분.
화밀 선택은 당분 잔량, 화분 선택은 화분 잔량 기준. 공급 부족 시 실제 확보량만 적재.
동반 수분은 당분 차감 비율대로 원천에서 차감하고 discardedWater에 기록.
중단 귀환은 차감 없음. 비행 중 선택한 밀원이 고갈되어도 다른 밀원으로 전환하지 않음.
기존 운반 용량(당분+화분), 요청 상한, 시간 기반 외부 이동은 유지.

검증 환경: Unity 6000.5.1f1, 원본과 분리된 validation 프로젝트, 배치 실행.

- 실재 두 벌통의 동일 밀원 경쟁 5:15 요구 / 12mg 재고 => 3:9mg.
- 독립 화분 비례 배분, 수분 비례 차감, 고갈, 자발적 중단, 운반/요청 상한.
- 출발 및 비행 중 잔량 유지, 완료 시 실제 차감, 빈 재고 출발 방지.
- 실제 수정 전 v19 저장 fixture 읽기, v20 정확한 왕복, 비행 중 저장 재개 후 벌 상태 바이트 동일 및 단일 차감.
- 무채집 기후/밀원 120틱 전체 snapshot: 수정 전 fixture와 바이트 동일.
- BeeCycleTests.Run: PASS 32 checks + BeeSurfaceTests + WorldSaveTests.

저장: 스키마20 / 벌 내부 형식2; 스키마17/18/19 읽기 유지.
v19 비행 중 벌은 과거 선택 밀원이 없으므로 남은 시간을 보존하고 첫 채집 완료 때 한 번 선택.
이전 자원/개체를 새로 생성하지 않으며 이전 설정에 잔량 선택 식을 보충.
테스트용 유한 재고는 테스트 코드에서만 설정; 실제 새 게임에 밀원 재고를 임의 추가하지 않음.

관찰 UI: 외부 벌의 선택 밀원과 남은 시간; 날씨 UI에 채집 후 잔량 mg 표시.
수식: forageSourceWeight(available=잔량mg), forageSugarAmount/foragePollenAmount(요청 상한), forageDuration.
forageSourceId는 초기 시험 먹이 화원에만 사용. forageWater/forageWaterAmount는 저장 호환용 미사용 값.

제한: 실제 에디터 플레이 화면/모바일 조작은 이번 작업에서 수동 검증하지 않음.
겨울 등 밀원 생산/잔량이 없는 조건에서는 외부 식량이 생기지 않음.
외부 경로·거리·기상별 비행 제한은 이번 범위에 추가하지 않음.
