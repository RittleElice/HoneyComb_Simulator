작업 기반 욕구 해소 — 2026-11-27

확정 규칙
- 자연감소1, 명령자극10 유지. 작업 감소계수는5부터 사용. 기존 경과시간 무작위 중단 유지.
- 벌마다 수정 가능한 욕구 목록. 저장 파일의 중복 압축만 유지하며 로드한 공유 스냅샷은 수정 전 개별 목록으로 전환.
- 실제 작업량만 해당 행동/목표 욕구에서 감소. 다른 목표와 다른 벌의 욕구는 변경하지 않음.
- 욕구0이면 Task 종료. 외부 채집 중이면 기존 경로로 귀환하며 순간 이동하지 않음.
- 더 할 일이 없는 목표 욕구는 삭제(0). 봉군/격자 수요는 여전히 자연감소만 적용.
- 건설 사용가능 판정80 유지. 이미 선택한 목표 격자의 건설 작업은100까지 가능. Task의 목표 단위는 기존 격자 유지.
- 한 틱 안에 이미 시작한 배분 요청은 끝까지 처리한 뒤 종료. 욕구가 부족하다고 현재 틱의 실제 작업량을 잘라내지 않음.

작업량 기준
workDesireRelief = actionRate*ratio
건설: 실제 배분 건설도 / buildPoints
육아: 실제 전달 당분+화분 mg / (nurseRate*대표배율). 두 자원을 각각 기본량만큼 전달하면 감소도 두 배.
발열: 실제 발열 시간(틱). 에너지가 부족해 부분 발열하면 그 시간만 반영.
정리: 실제 꺼낸 자원량 / (acquireRate*대표배율)
산란: 실제 산란한 알 수. 산란 시도 실패는0.
화밀/화분: 실제 확보량 / (해당 채집속도*대표배율)
각 행동의 actionRate는 workBuildRelief 등 별도 파라미터이며 기본5.
이동/먹이 확보/작업 요청만 있고 실제 수행0은 작업 감소0. 섭식·휴식·회복·저장은 기존 상태 기반 욕구와 종료를 유지.

목표 해소 판정
건설: 격자에 건설도100 미만 소방이 없음.
육아: 현재 유충의 당분·화분60틱 비축이 모두 충족됨. 알/번데기만 있으면 육아 필요 없음.
발열: 봉충 없음 또는 현재 격자 온도34도 이상.
산란: 빈 사용가능 소방 없음.
정리: 대상의 정리 예약이 해소되거나 자원 없음.
채집: 적재 여유 없음. 일시적인 밀원 고갈은 해결된 목표로 취급하지 않고 기존 대체밀원 탐색·부족확률 귀환을 유지.
명령 수요가 남아 다시 욕구를 자극하더라도 목표가 해소됐다면 선택 전에 삭제. 배분 후 다시 검사해 다른 벌의 기여도 반영.

파라미터
기존 벌 관찰 도구의 파라미터에서 ‘작업에 따른 욕구 해소’ 항목.
workDesireEnabled=0은 이전 동작 비교용. 계수·수식 변경 가능.
