격자별 열·수분 수지 계산 (새 게임 기준)
내부 열전달: G=A/(dA/kA+dB/kB). 열전도율은 각 재질의 W/(m K) 값이며 소비장 방향성은 기존 복합 재질 계산을 사용합니다.
60초 후 온도를 전체 열용량 기반 후진 오일러 방식으로 풉니다. 수분은 온도 고정 단계에서 목재 비선형 흡습 곡선을 포함한 수분 수지를 풀고, 수증기 이동 에너지를 열수지로 전달합니다. 단일 틱에 수분→열 순서이며 완전 연성 수렴 반복은 하지 않습니다.
내부 공기를 외기 상태로 고정하지 않습니다. 외부는 유한한 열·수분 경계 교환으로만 작용합니다.
삭제: 내부 재질 조합별 h 10개, 외기 강제 온도·수증기압 대입, 사각뿔 1/6 이동량 제한의 실제 실행 경로, LegacyMoisture 우회 계산.
공기 유효 체적 열용량0: 밀도1.2×비열1004=1204.8 J/(m3 K). 새 게임용이며 기존 에너지 저장 세이브의 온도를 보장하지 않습니다.
외부 열교환: 외부 공기 물질 Resources/Thermal/ExteriorAir를 사용합니다. 유효 외부 열전도율 ke=ConductivityWPerMK×HeatTransferMultiplier. 기본 두께 d0, 풍속 v에 대해 d_eff=d0/(1+WindCoefficient×v×d0/ke), G=A/(d_inside/k_inside+d_eff/ke). 공기·목재·소비장·단열재 모두 같은 식이며 내부 저항은 보존됩니다. 풍속을 경계 전체에 병렬 가산하지 않습니다.
외부 공기 임시 기본값: 열전도율0.0254 W/(m K), 전달 보정4, 기본 두께0.015m, 풍속계수4 W/(m2 K)/(m/s). 두께5/15/35mm는 비교 대상이며 기본15mm는 임시 중간값입니다. 실측 보정값이 아닙니다.
외부 공기는 유한 열용량 격자가 아니라 날씨 온도가 고정된 경계 물질입니다. 내부에서 나온 열로 외기 온도를 바꾸지 않습니다. 내부 공기 보정과 외부 공기 보정은 별도 파라미터입니다. 기존 재질별 외기 열계수와 경계 전체 풍속 가산은 현재 기후 수지 경로에서 사용하지 않습니다.
공기 투습1.85e-10, 목재2e-12 kg/(m s Pa), 외기 공기막0.01m, 수분 풍속계수0.025. 기존 습윤 재료 근사와 증발 법칙 유지.
선형 상대오차1e-11, 수분 상대오차1e-10, 절대오차1e-12kg, 선형최대3000회, 비선형최대30회. 실패 시 상태를 임의 보정하지 않고 오류로 중지합니다.
Tools/HoneyComb/재질 파라미터 설정에서 활성 값만 편집합니다. 기존 asset/script GUID와 저장 구조는 유지합니다.
과거 비교용 커널은 UNITY_EDITOR에서만 컴파일되어 과거 시험 기록 재현에 사용하며 플레이어 실행에는 포함되지 않습니다.
