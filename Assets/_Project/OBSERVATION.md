# 관찰 화면 1차

Play를 재시작하면 기존 긴 개발 패널 대신 ObservationPanel이 표시된다.
상단 시간/일시정지/1시간/입력 시간 진행은 고정이며 본문만 스크롤한다.
Screen.safeArea를 적용하고 세로 기준 크기로 축소/확대한다.
시뮬레이션 모델과 기존 개발용 컴포넌트는 유지했다. Runner의 표시 연결만 변경했다.

양봉장: 금색 벌통 도형, 녹색 빈 땅, 선택 칸 강조. 좌표와 야외 벌 수, 벌통 내부 벌 수 표시.
칸 클릭 → Open Hive. 빈 칸에서 Place Hive, 벌통 이동 선택 후 빈 칸에서 이동 가능.
Outdoor / base / outside bees 버튼은 장소별 기존 배치/조회/이동 도구를 필요할 때만 펼친다.

벌통: 위에서 아래로 계상 카드가 쌓이고 각 계상은 10개 슬롯을 2줄로 표현한다.
금색은 소비장이 있는 슬롯, 어두운 칸은 빈 슬롯. 슬롯을 누르면 해당 슬롯 화면으로 이동한다.
단상은 계상 아래에 표시되며 클릭하면 장소별 벌 도구를 펼친다.

소비장: Overview / Cells / Bees / Move-Remove 탭으로 분리한다.
Overview는 건설도 막대와 양면 완성 소방 통계를 표시한다.
Cells는 기존 특정 소방/양면 건설도 편집, Bees는 개별 벌 추가/조회/장소 이동이다.
Move / Remove에서 소비장을 이동 대상으로 지정한 뒤 다른 벌통의 빈 슬롯을 열면 이동할 수 있다.
벌이 있는 Frame과 봉군/거주 벌이 있는 Hive의 삭제 제한은 기존 모델을 따른다.

Apiary와 < Hive 버튼으로 되돌아간다. 이동 중인 소비장/벌은 화면 상단에 표시된다.
정식 아트가 아닌 IMGUI 기반 관찰용 시각화다. Unity GameObject는 벌통/벌별로 생성하지 않는다.
현재 작업은 양봉장·벌통 구조를 먼저 시각화한 단계다. 소방 90x40 자체의 확대 가능한 격자/육각형 렌더링은 다음 단계다.
Unity 라이브러리 기준 컴파일은 검증했으며 에디터/Android 실화면 렌더링은 별도 확인이 필요하다.
