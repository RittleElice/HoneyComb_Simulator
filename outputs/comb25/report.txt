25×12 소방 적용 및 검증

적용 대상: C:/UnityProject/HoneyComb_Simulator
- 한 면 300개, 양면 600개.
- 소비장 440×220mm, 소방 배치 영역 420×200mm, 열·수분 공간 격자 5×2×3 유지.
- 공간 격자 한 칸당 논리 소방 5×4=20개 연결.
- 건설도 80% 완성, 완성 후 51~79% 유지, 50% 이하 내용물 제거 규칙 유지.
- 전체 액체 저장 용량 1,989mL, 화분 저장 용량 1,326g 유지.
- 소방당 액체 3.315mL, 화분 2,210mg. 설정 자산과 코드 기본값 일치 확인.
- 모두 일벌 소방·100% 건설 기준 건설 밀랍 99.45g + 소초 45.98g 유지.
- 수벌 소방·부분 건설 밀랍 총량 보존 검증.
- 봉충 소방당 1개체 유지, 두 번째 봉충 저장 거부 검증. 벌 행동 변경 없음.
- 기존 저장 정책 C 유지: Saves-Comb25x12 / 형식 17로 신규 저장.
  형식 16 이하 거부, 이전 저장은 변환·이동·삭제하지 않음.

검증 결과
- 실제 원본 프로젝트를 Unity 6000.5.1f1 batchmode로 컴파일 및 실행.
- Comb30Validation.Run (기존 클래스명 유지, 메뉴는 Run Comb 25x12 Validation): 4,260개 검증 통과.
- ReducedGridIntegrationTests: 104,550개 검증 통과.
  3단·30소비장, 60틱 열·수분 계산, 모든 30개 증발 영역, 소비장 이동/재장착,
  저장 왕복 및 재개. 재개 최대 온도 차 3.54648932443524E-07°C.
- CombGeometryTests, CellStateTests, CombThermalTests,
  ContentThermalIntegrationTests, WorldSaveTests, BeeSurfaceTests 통과.
- 실제 손 소비장 프리팹 양면 렌더링 및 600개 소방 중심점 선택 통과.
- 컴파일 오류 및 테스트 예외 없음. 기존 미사용 필드/API 사용 중단 경고 존재.
  시작 시 라이선스 토큰 갱신 경고가 있었으나 entitlement 확인 후 컴파일/검증 정상 완료.
- git diff --check 통과. 씬·프리팹·프로젝트 설정 변경 없음.
