3. Inspector 사용
Assets/Resources/ActionButtonCatalog.asset을 선택해 entries에서 ID별 설정 편집.
Observation/Apiary 씬의 root Canvas에 ActionButtonManager가 연결되어 있고 Catalog 참조가 지정되어 있음.
기존 buttonPrefab, selection, presenter, actionLayer, backButton 참조는 변경하지 않음.
동적 버튼은 실행 중 ActionButtonView/Positioner가 붙음. 프리팹에 중복으로 붙일 필요 없음.
Fixed: 루트 Canvas의 정규화 anchor(0~1) + offset. 뒤로가기 기본값.
FollowTarget: 기존 장비/바닥/소비장 선택 추적점 + 간격 + offset. 놓기/결합/격왕판 기본값.
Relative: 다른 RectTransform 기준 anchor + offset. View의 Relative Target이 비어 있으면 부모 기준.
Use Layout Slot: Relative에서 기존 LayoutGroup 슬롯 유지. 관찰 진입/들기/소비장 넣기/꺼내기 기본값.
Relative에서 원하는 절대 기준점을 쓰려면 Use Layout Slot을 끄고 anchor/offset 설정.
크기/오프셋/여백은 Canvas UI 단위. CanvasScaler에 따라 실제 픽셀 크기는 달라짐.
Show Label을 끄면 아이콘만 표시. 아이콘이 없는 경우 안전하게 텍스트 표시.
동적 층수·뚜껑 들기 등 상황별 문구는 기존 컨트롤러의 문구를 유지.
기존 UI_Observe/UI_UP/UI_Down Sprite를 재사용했으며 뒤로가기는 위 화살표를 90도 회전.
여러 행동이 화살표를 공유하므로 기본값은 아이콘+텍스트. 행동별 전용 그림은 각 icon 슬롯에서 교체 가능.
